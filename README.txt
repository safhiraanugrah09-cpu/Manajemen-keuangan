# FinansialKu — Website Manajemen Keuangan Pribadi

## Cara menjalankan
1. Ekstrak ZIP ini.
2. Buka folder `manajemen_keuangan_pribadi`.
3. Klik dua kali `index.html`, atau buka folder menggunakan VS Code lalu jalankan dengan ekstensi Live Server.
4. Pastikan internet aktif saat pertama kali membuka agar Chart.js dan Google Fonts dapat dimuat.

## Fitur
- Dashboard saldo, total pemasukan, dan total pengeluaran.
- Tambah transaksi pemasukan/pengeluaran.
- Kategori transaksi, tanggal, dan catatan.
- Pencarian dan filter transaksi.
- Hapus transaksi.
- Grafik arus keuangan dan komposisi pengeluaran.
- Laporan kategori dan ekspor CSV.
- Data disimpan di browser menggunakan localStorage.

## Catatan
Versi ini adalah frontend tanpa backend/login. Data tersimpan di browser/perangkat yang digunakan. Jika cache atau data situs dihapus, data localStorage dapat ikut terhapus. Untuk penggunaan multi-pengguna dan sinkronisasi antarperangkat, perlu ditambahkan backend dan database.
